## Project

Arcade Vault is an online platform for playing games and competing for the highest score. The project is in its starting state (fresh `create-next-app` scaffold); the README and docs are in Spanish.

Development follows Spec Driven Design using the `/spec` and `/spec-impl` skills from https://github.com/Klerith/fernando-skills (install with `npx skills@latest add Klerith/fernando-skills`). Write a spec before implementing new features.

## Commands

- `npm run dev` — dev server (Turbopack)
- `npm run build` — production build (also the type-check, since `tsconfig` has `noEmit`)
- `npm run lint` — ESLint 9 flat config (`eslint-config-next` core-web-vitals + typescript)

No test runner is configured yet.

## Stack and non-default configuration

- Next.js 16.4 (App Router, `app/` directory) with React 19.3 and TypeScript strict mode. Next.js APIs here differ from older versions — check `node_modules/next/dist/docs/` (`01-app/`, `03-architecture/`) before using an API.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. With Cache Components on, data fetching and caching follow the `"use cache"` / Suspense model rather than the old `fetch` cache options — read the docs before writing data-loading code.
- Tailwind CSS v4 is loaded through a Turbopack loader rule (`@tailwindcss/turbopack` on `*.css`), not PostCSS. There is no `tailwind.config` or `postcss.config`; theme tokens live in `app/globals.css` under `@theme inline`.
- Layouts and pages use the global typed props helpers (e.g. `LayoutProps<"/">`, `PageProps<...>`) generated by Next into `.next/types`.
- Import alias `@/*` maps to the project root.
